🎨 Générateur OG images — Nextiweb Studio

Instructions :

1. Cliquez sur « 📥 Télécharger JPG » à droite de chaque carte pour exporter une image (JPG q85, ~100 KB).

2. Ou cliquez sur « Tout télécharger » en bas pour exporter les 12 JPG d'un coup.

3. Les images sont générées à 1200×630 px exactement, JPG quality 85, prêtes pour Open Graph / Twitter Cards.

4. Déposez les 12 PNG dans le dossier assets/images/ du repo, puis commit + push.

Astuce alternative : chaque carte peut aussi être capturée via Chrome DevTools → clic droit sur la carte → Inspect → ⋮ → Capture node screenshot.
